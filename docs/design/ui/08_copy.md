## 漢字と学年

子どもに見せる文の漢字は、表示の学年までに習う字だけにする（D-91）。

- 配当表：小学校学習指導要領（平成29年告示）別表の学年別漢字配当表（1026字）。コードでは `web/src/data/kanji-grades.ts` に置く。
- 出し分け：表示の学年以下の字だけでできた語は漢字のまま出し、ふりがなは付けない。学年より上の字か、配当表に無い字を1字でも含む語は、語ごとひらがなで出す。「やく分」のような交ぜ書きはしない。
- 持ち方：漢字の語には全部 `[語|よみ]` を付け、読みはコードに持つ。この表は漢字のまま書き、読みを2か所に持たない。
- 対象：PG-001、PG-002、PG-003 の文。`research/`、画面に出ない `data/curriculum.ts`、作品名（Q-05）は外す。
- 読み上げ：名前（plainText）も、見える文と同じ学年の形にする。
- 学年：アカウントの `grade` で決まり、見本アカウントは5年。子どもは変えない。開発中だけ CMP-027 で変える（D-144）。
- 見ないこと：字ごとの音訓。字の学年だけで決める。
